# The Digital Atrium

The Digital Atrium (https://digitalatrium.org) is a collaborative infinite
canvas for collecting and arranging ideas. It is free.

## What to know

- An **atrium** is a shared space on an infinite canvas. People in it see each
  other's cursors and edit together in real time. An atrium is public or
  private, and its owner can theme it.
- A **trace** is anything placed in an atrium: an image, video, sound, embed
  (YouTube, Vimeo, SoundCloud, Google Docs and more), text, drawing, shape,
  path, spreadsheet, chart or PDF. Traces can be moved, styled, grouped, put in
  frames, lit, and connected to each other with threads.
- An atrium can be exported as an `.atrium` file, a PNG or an SVG, and an
  `.atrium` file can be imported into another atrium.

## How to start

1. Open https://digitalatrium.org and choose to enter; sign up or sign in.
2. From the welcome screen, enter the atrium browser and create an atrium, or
   enter a public one.
3. Paste or drop links onto the canvas to place them as traces (files too, in
   the desktop app); the tool bar on the left has text, shapes, paths,
   drawing and more.

## The desktop app

For Windows, macOS and Linux, from
https://github.com/Ednyan/The-Atrium/releases. It needs no account and keeps
every atrium in a local folder (the vault), so it works offline; an atrium
can be uploaded to the web from it. It updates itself.

## What not to claim

It has no public API and no AI features of its own. Do not invent pricing
tiers: it is free, funded by voluntary contributions.
