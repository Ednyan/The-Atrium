# Keyboard shortcuts

Keys don't act while you're typing in a box. On a Mac, use **Cmd** for **Ctrl**.
The short list is also under **Atrium menu** > **Controls**.

## Moving around

| Key | What it does |
|---|---|
| **H** | Move the view tool, on or off |
| **+**, **−** | Zoom in, out |
| **0** | Zoom to 100% |
| **Shift+1** | Fit everything in view |
| **F11** | Fullscreen |

## Tools

The number keys stay with their tool even if you reorder the bar.

| Key | Tool |
|---|---|
| **1** | Select |
| **2** | Text |
| **3** | The shape in use |
| **4** | Path |
| **5** | Draw |
| **6** | Image |
| **7** | Embed |
| **8** | Frame |
| **M** | Selection (area or lasso), on or off |
| **K** | Laser pointer, on or off |
| **D** | Draw, on or off |
| **T** | Paste a link where the pointer is |
| **I** | Take the colour under the pointer into your palette |
| **Esc** | Put the tool down, or deselect |
| **Enter** | Finish a path |

## While drawing

| Key | What it does |
|---|---|
| **E** | Eraser, on or off |
| **Ctrl+Z**, **Ctrl+Shift+Z** | Undo, redo a stroke |
| **Esc** | Leave drawing |

## Selected traces

| Key | What it does |
|---|---|
| **Delete** or **Backspace** | Delete |
| **Ctrl+C**, **Ctrl+V** | Copy, paste at the pointer |
| **Ctrl+Alt+C**, **Ctrl+Alt+V** | Copy, paste style |
| **Ctrl+G** | Group |
| **Ctrl+Shift+G** | Ungroup |
| **G** | Select the whole group of the selected trace |

## Mouse with keys

| Do this | What it does |
|---|---|
| **Shift+click** | Add a trace to the selection |
| **Ctrl+click** | Select the trace itself, even inside a group or frame |
| **Shift+drag** on the canvas | Select an area |

## Atrium

| Key | What it does |
|---|---|
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo |
| **Ctrl+S** | Save changes |
| **Ctrl+Shift+E** | Export |
| **?** | Help |
| **→**, **←** | Next, previous location, while presenting |

## Overlay mode (desktop)

| Key | What it does |
|---|---|
| **Ctrl+Shift+A** | Always on top |
| **Ctrl+T** | Click-through |
| **Ctrl+Alt+Shift+X** | Leave overlay mode, from anywhere |
