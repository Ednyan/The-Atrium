# Where atriums live

You choose where an atrium is kept when you make it.

| | In this browser | Online (the Atrium's cloud) | In Google Drive | Desktop app |
|---|---|---|---|---|
| **Needs** | Nothing | An account | A Google sign-in | The app |
| **Space** | No set limit | Up to 3 atriums, 50 MB in all | Your Drive's free space | Your disk |
| **Other people** | No | Yes, by invitation | Yes, people you add | No |
| **Can be public** | No | Yes | Yes | No |
| **Other devices** | No | Yes | Yes | No |

## Which to choose

| You want | Choose |
|---|---|
| To try it, with no account | **In this browser** |
| To share a small atrium, on any device | **Online** |
| To share a large atrium, or keep it encrypted | **In Google Drive** |
| Everything as files on your computer, with no limit | **Desktop app** |

## Good to know

- **A browser atrium is only in that browser.** Clearing the site's data deletes
  it. Save a copy with **Export**, as an `.atrium` file.
- **A link can't open a browser or desktop atrium.** To share one, export it as
  an `.atrium` file or put it online.
- **One file can be up to 25 MB** in the Atrium's cloud.
- **The desktop app works offline.** If you sign in, it can also open atriums
  shared with you.
- An atrium can change place later. See [Moving atriums](../keeping-and-moving/moving-atriums.md).
